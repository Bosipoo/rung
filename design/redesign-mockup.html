DAY 6 · SATchallenge

Two 8-kyu string katas + the debug drill

Read the code and find the bugs BEFORE running it. Fix them. Then reveal.

name = input("Name: ")
age = input("Age: ")
if age > 18
    print("Adult: " + name)
else:
    print("Minor: " name)
Reveal solution
1) age is text — int(input("Age: ")) before comparing. 2) The if line is missing its colon. 3) "Minor: " name is missing the + (or use an f-string).
